# maborak/homebrew-tap

Homebrew formulae for [mabo-ctl](https://github.com/maborak/mabo-ctl), a
per-repo local dev process supervisor.

```sh
brew install maborak/tap/mabo-ctl
```

`Formula/mabo-ctl.rb` is generated by mabo-ctl's release workflow
(`packaging/homebrew/formula.sh`) on every release. Do not edit it by hand.
